# Лабораторная работа 2

## Задание

Задача 2. Создать функцию isBalanced(str), проверяющую сбалансированность скобок
()[]{} в строке (например: "{[()]}" → true, "[(])" → false).

## Реализация

Экспортируется функция isBalanced. Создаётся объект-словарь, в котором каждой
открывающей скобке соответствует парная закрывающая: ( → ), { → }, [ → ].
Заводится пустой массив — стек для незакрытых открывающих скобок. Строка
перебирается посимвольно слева направо. Если текущий символ есть среди ключей
словаря, то есть является открывающей скобкой, — он кладётся в стек. Иначе
проверяется, что стек не пуст и что верхний элемент стека, то есть последняя
незакрытая открывающая, является парной для текущего символа по словарю: если
стек пуст или пара не совпадает — функция возвращает false. Если оба условия
выполнены, верхний элемент снимается со стека (pop). После прохода по всей
строке функция возвращает true, только если стек пуст, — то есть все открывающие
скобки получили свою пару.

## Запуск

Импортируйте именованный export из `solution.js` как ES module.
