# Лабораторная работа 3

## Задание

Задача 3. Реализуйте функцию findPairsWithSum(arr, sum), которая возвращает все
пары чисел, дающие в сумме sum.

## Реализация

Экспортируется функция findPairsWithSum, которая принимает массив чисел arr и
целевую сумму sum и возвращает массив уникальных пар чисел из arr, дающих в
сумме sum. Заводятся три коллекции: seen — множество чисел, которые уже
встречались при проходе слева направо; pairs — массив найденных пар; used —
множество уже добавленных пар, чтобы не дублировать результат. Массив
перебирается по одному элементу. Для каждого числа num вычисляется «недостающее»
число need = sum - num. Затем проверяется, есть ли need в множестве seen, то
есть встречалось ли это число раньше. Если да — значит, текущее число и need
образуют пару с нужной суммой. Оба числа упорядочиваются по возрастанию (a —
меньшее, b — большее), чтобы одна и та же пара, найденная в разном порядке,
имела одинаковый ключ. Из a и b формируется строковый ключ вида "a,b". Если
такого ключа ещё нет в used — пара добавляется в результат pairs, а ключ
помечается использованным в used. В конце каждой итерации текущее число num
добавляется в seen, чтобы на следующих шагах его можно было найти как
«недостающее». После прохода по всему массиву возвращается массив pairs со всеми
уникальными парами.

## Запуск

Импортируйте именованный export из `solution.js` как ES module.
