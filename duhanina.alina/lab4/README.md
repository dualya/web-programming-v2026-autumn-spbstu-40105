# Лабораторная работа 4

## Задание

Задача 4.

4.1. Создать класс car с полями: • make — марка (строка) • model — модель
(строка) • owners — массив имён владельцев (строки) Реализовать методы: •
addOwner(name) — добавить владельца • removeOwner(name) — удалить владельца •
геттер ownerCount — количество владельцев

4.2. Дан массив автомобилей: • Реализовать функцию, которая группирует
автомобили по марке • Реализовать функцию, возвращающую уникальных владельцев •
Реализовать функцию, которая группирует автомобили по количеству владельцев •
Реализовать функцию, которая возвращает автомобили с владельцем по имени •
Реализовать функцию, которая возвращает список моделей для заданной марки

4.3. Реализовать пользовательский интерфейс: • Карточки автомобилей: марка,
модель, список владельцев • Кнопки: "Добавить владельца", "Удалить владельца",
"Добавить автомобиль", "Удалить автомобиль" • Форма добавления автомобиля
(марка, модель). Форма добавления владельца • При любых изменениях автоматически
обновлять пользовательский интерфейс • Все операции добавления/удаления
выполнять асинхронно через Promise

- setTimeout() • Использовать local storage для сохранения текущего списка
  студентов при закрытии вкладки.

## Реализация

Модель реализована в файле model.js. Класс Car содержит поля make, model,
owners, методы addOwner, removeOwner и геттер ownerCount. Функции groupByMake,
getUniqueOwners, groupByOwnerCount, carsByOwner, modelsByMake реализованы.

Логика интерфейса реализована в файле main.js. Функция render полностью
перерисовывает список карточек и выпадающий список при каждом изменении массива
cars. Формы обрабатывают событие submit, значения читаются через FormData.
Кнопки в карточках позволяют добавить владельца через prompt, удалить владельца
и удалить автомобиль.

Все операции изменения проходят через функцию asyncOp, которая оборачивает
действие в Promise с задержкой setTimeout. Сохранение в localStorage выполняется
после каждого изменения и при закрытии вкладки через событие beforeunload. При
загрузке данные из localStorage восстанавливаются, простые объекты превращаются
обратно в экземпляры класса Car.

Стили описаны в файле styles.css.

## Запуск

Откройте index.html в браузере.
