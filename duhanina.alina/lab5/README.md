# Лабораторная работа 5

## Задание

Задача 5. Создать игру “Змейка”
Создайте классическую игру "Змейка" с использованием React. Игрок
управляет змейкой с помощью клавиатуры, собирает еду для роста и избегает
столкновений с границами экрана и собственным хвостом.
Функциональность:

- управление змейкой (клавиши WASD или стрелки);
- рост змейки при поедании еды;
- увеличение счета (+10 за каждую съеденную еду)
- конец игры при столкновении с границей поля или с собственным
  хвостом;
- рестарт игры (кнопка "Новая игра").
  Логика игры:
- змейка движется с постоянной скоростью
- еда появляется в случайной клетке (кроме тех, где находится змейка)
- при съедании еды: змейка удлиняется, появляется новая еда, cчет
  увеличивается.

## Реализация

Приложение построено на React 18 с использованием функциональных компонентов
и хуков. Проект собирается через Vite. Точкой входа служит файл src/main.jsx,
который монтирует корневой компонент App в элемент <main data-testid="app">,
описанный в index.html. Стили подключаются из src/styles.css.

Игровые константы и чистые функции вынесены в отдельный модуль src/game.js.
Там хранятся размер поля, начальная скорость, шаг ускорения, минимальная
скорость, функция создания начальной змейки и функция генерации еды в
случайной свободной клетке. Это позволяет отделить данные и вычисления от
React-логики, а также тестировать их независимо от компонентов.

Основной компонент App хранит всё состояние игры через хук useState.
В нём хранятся массив сегментов змейки, координаты еды, текущее направление
движения, флаг окончания игры, счёт, интервал между ходами, флаг паузы и
флаг начала игры. Дополнительно используется useRef для хранения актуального
направления движения, чтобы избежать проблем с замыканием внутри setInterval.

Игровое поле представлено сеткой 20 на 20 клеток. Змейка — массив объектов
с координатами x и y. Голова змейки — первый элемент массива. На каждом
ходе вычисляется новая позиция головы, после чего проверяются столкновения
со стеной и с собственным хвостом. Если змейка съедает еду, новый сегмент
добавляется без удаления хвоста, счёт увеличивается на 10, а интервал между
ходами уменьшается, пока не достигнет минимального значения. В противном
случае хвост удаляется, и змейка просто смещается.

Управление реализовано через подписку на событие keydown объекта window
внутри useEffect. Поддерживаются клавиши WASD и стрелки. Разворот на 180
градусов запрещён. Пауза включается и выключается пробелом или клавишей
Escape. Игровой цикл запускается через setInterval, который пересоздаётся
при изменении скорости или состояния паузы и очищается при размонтировании
компонента.

Еда генерируется функцией generateFood, которая собирает список всех
свободных клеток поля и выбирает одну случайную. Это гарантирует, что
еда никогда не появится на змейке. При поедании еды вызывается эта же
функция для создания новой порции.

При открытии приложения игра не начинается сразу: поверх поля показывается
стартовый экран с кнопкой «Начать игру». После клика змейка начинает
движение. Игрок нажимает клавиши WASD или стрелки, чтобы задать направление
движения. Змейка движется самостоятельно с постоянным интервалом, а игрок
только меняет направление. При попадании головы змейки на клетку с едой
змейка удлиняется на один сегмент, счёт увеличивается на 10 очков, а новая
еда появляется в случайной свободной клетке. Если змейка сталкивается
со стеной поля или с любым сегментом собственного хвоста, игра завершается
и поверх поля показывается сообщение об окончании игры с итоговым счётом.
Кнопка «Новая игра» сбрасывает состояние к начальному и сразу запускает
новую партию без дополнительных кликов. Также в любой момент игры можно
поставить её на паузу и снять с паузы клавишей Пробел или Escape.

## Запуск

Выполните `npm install`, затем `npm run dev` в каталоге лабораторной.
